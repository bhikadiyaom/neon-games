PUTTING NEON ARCADE ONLINE (anyone, anywhere)
=============================================
What you get: ONE web address with a lobby. Visitors press "Create private room" for Neon Strike or
Neon Arena, get a 4-letter code + invite link, and send it to friends. Each room is its own match, so
strangers never end up in the same game. Rooms close by themselves when empty. Nothing to install.

Try it on your own PC first:  double-click "Start Online Hub (test).bat"  (opens http://127.0.0.1:3050).

STEP 1 - GitHub (once)
  Create a repository on github.com, then in D:\Games:
      git remote set-url origin https://github.com/YOUR-USERNAME/YOUR-REPO.git
      git push -u origin main
STEP 2 - Render
  render.com > New > Blueprint > pick the repo > Apply. You get a link like https://neon-arcade.onrender.com.
STEP 3 - Make it yours
  - Buy a short, unique domain (Namecheap / Cloudflare, about $10-15 a year).
  - Render > the service > Settings > Custom Domains > add it; Render shows the 2 DNS records to create.
  - To rename the brand, edit the title/heading in landing.html ("NEON ARCADE") and push.
STEP 4 - Keep it fast
  Free plan sleeps after ~15 min idle (first visitor waits up to a minute). Plan "starter" (about $7/month)
  stays awake: change  plan: free  to  plan: starter  in render.yaml, or pick it in the Render dashboard.

LIMITS / SAFETY
  - MAX_ROOMS (default 8) rooms at once; each room holds up to 8 players. Raise MAX_ROOMS only with a bigger plan.
  - 4 room creations per visitor per minute. Rooms are private: only people with the link or code get in.
  - The person who creates a room is its host (dashboard: bots, mode, win score). Others see it read-only.
  - No accounts, no chat, no saved scores: everything lives in memory and disappears when the room closes.
  - LAN play (Start ... .bat files) still works exactly as before.
