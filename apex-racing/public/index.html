YOUR BROWSER CAN'T RUN THE 3D ENGINE YET

Neon Apex GP draws its graphics with WebGPU, the modern graphics system in current browsers.

HOW TO FIX IT

  1. Use the latest Google Chrome or Microsoft Edge on Windows, macOS or ChromeOS (version 113 or newer). Current Safari and Firefox on Windows also work.
  2. Turn on graphics acceleration: open chrome://settings/system, switch on "Use graphics acceleration when available", then restart the browser.
  3. Check chrome://gpu: the line WebGPU should say "Hardware accelerated".
  4. On Linux or older graphics cards, open chrome://flags/#enable-unsafe-webgpu, set it to Enabled and restart.
  5. Update your graphics driver if the steps above do not help.
